# pertemuan 1
1. kesinambungan PWD–DPW–DPWL;
jawaban: 
- PWD (Pemrograman Web Dasar) membahas tentang dasar-dasar pembuatan web seperti HTML, CSS, dan dasar PHP
- DPW (Dasar Pemrograman Web) mengembangkan kemampuan dengan membuat web yang sudah menggunakan database dan proses CRUD.
- DPWL (Dasar Pemrograman Web Lanjut) melanjutkan membuat aplikasi yang lebih teratur, salah satunya menggunakan konsep MVC.

kesinambungannya : Artinya, materi dari PWD menjadi dasar untuk mempelajari DPW, kemudian kemampuan dari DPW dikembangkan lagi di DPWL untuk membuat aplikasi web yang lebih kompleks dan terstruktur.

2. perbedaan PHP terstruktur dan MVC;
jawaban : 
PHP Terstruktur : 
Kode lebih Sederhana, Loogika dan tampilan bisa bercampur, cocok untuk aplikasi sederhana.
MVC : Kode lebih terstruktur, logika dan tampilan dipisahkan, cocoko untuk aplikasi yang lebih besar 

3. fungsi Model, View, dan Controller;
Jawaban :
- Model berfungsi untuk mengatur data dan berhubungan dengan database.
- View berfungsi sebagai tampilan yang dilihat oleh pengguna.
- Controller berfungsi sebagai menguhubungkan antara Model dan View dan juga mengatur proses dari request pengguna.

4. alur request–response MVC;
Jawaban : 4. Alur MVC secara sederhana adalah:
User → Request → Controller → Model → Database

Kemudian hasilnya kembali:
Database → Model → Controller → View → Response → User

5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan; dan
Jawaban :
fitur : 1. menampilkan data 
        2. Tambah data 
        3. edit data 
        4. Hapus data 
model : 1.mengambil data dari database 
        2. menyimpan data 
        3. mengubah data
        4. menghaous data
controller : 1. memproses data 
            2. memproses input 
            3. memproses perubahan 
            4. memproses perintah hapus
view : 1. menampilkan data 
        2. from tambah data
        3. from edit 
        4. tombol hapus
alasannya : 
-Karena data harus diambil dari database lalu ditampilkan

-User mengisi data melalui form dan data disimpan ke database

-Data yang diubah harus diproses lalu disimpan

-Controller menjalankan perintah dan Model menghapus data

-User memasukkan akun, kemudian sistem mengeceknya

6. kesimpulan P1.
Dari materi P1 dapat disimpulkan bahwa PHP terstruktur dan MVC sama-sama digunakan untuk membuat aplikasi web, tetapi memiliki cara pengorganisasian kode yang berbeda. PHP terstruktur lebih sederhana, sedangkan MVC membagi aplikasi menjadi Model, View, dan Controller sehingga kode lebih teratur.
